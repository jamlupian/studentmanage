# Student Management System (PHP + MySQL)

## Setup (XAMPP + VS Code)
1. Copy this folder to `C:\xampp\htdocs\student_management` (keep the folder name, or edit BASE_URL in config/db.php).
2. Start **Apache** and **MySQL** in the XAMPP Control Panel.
3. Open http://localhost/phpmyadmin -> Import -> choose `database.sql` -> Go.
4. Open http://localhost/student_management

## Default admin
- Email: admin@school.test
- Password: admin123  (change it after first login)

Students register themselves at /register.php. Admins can add, edit, search, and delete students.
